Цифровой секретарь деканата 

Интеллектуальная система для автоматической проверки студенческих справок, заявлений и нормативных документов вуза на базе локальных технологий OCR и RAG (LLM).


Проблема и решение
Проблема: Сотрудники деканата тратят часы на ручную проверку правильности заполнения справок и сверку со сложными регламентами вуза.
Решение: Наш сервис за секунды сканирует документ, извлекает ключевые данные (ФИО, даты, наличие печатей), находит нужный пункт в «Положении о приеме» и выдает готовый вердикт: «Документ принят», «Чего-то не хватает» или «Нарушен пункт правил».



Стек технологий
Интерфейс (Frontend): HTML5, JavaScript
Бэкенд: Python 3, FastAPI 
Компьютерное зрение (OCR): PaddleOCR, OpenCV (cv2)
Поиск и База знаний (RAG): `rank-bm25`, текстовые правила вуза (`rules.md`)
Локальная ИИ-модель: `llama-cpp-python` (работа с GGUF-моделями без отправки данных в облако)

Используемые ИИ-модели
1. Распознавание текста: Локальная предобученная модель PaddleOCR.
2. Языковая модель: Qwen2.5-1.5B-Instruct-GGUF (метод квантования Q4_K_M, вес ~1.2 ГБ). Отвечает за финальную классификацию сценариев проверки, интеллектуальный аудит логических ошибок и генерацию понятных пользователю ответов.

Инструкция по развёртыванию и запуску
1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.10+, и выполните команду для установки локальных библиотек и драйверов сборки:
pip install -r requirements.txt
2. Подготовка файлов
 Поместите Положение вуза в папку data/rules.md.
 Примечание: Создавать вручную или скачивать веса LLM-модели не требуется. В бэкенд встроен модуль автоматического скачивания — при первом запуске сервера скрипт сам загрузит веса Qwen2.5 напрямую с Hugging Face в директорию model/.
3. Запуск веб-сервера
Запустите асинхронный сервер uvicorn из корневой папки проекта:
```bash
uvicorn backend:app--reload --host 127.0.0.1 --port 8000
```
4. Работа с интерфейсом
Откройте любой современный браузер и перейдите по адресу:
👉 `http://127.0.0`
